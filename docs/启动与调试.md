# 启动与调试（新会话必读）

**不要手打 dsh web 参数，用脚本。**

``powershell
pwsh -File scripts\web.ps1 -Book "E:\workspace\novel-workspace\novel_demo" -Port 18085
``

脚本：杀端口 → 在书目录启动 → 等出带 token 的地址 → 自检 login 与 /novel-api/state 是否 200 → 打印 URL。

## 三条硬规则
1. cwd 必须是书目录（插件按 会话工作目录 → DSH_NOVEL_ROOT → process.cwd 找书）。
2. token 每次重启都会变，旧 URL 失效。
3. index.js 改动必须整进程重启；只有 client.js 会热替换。

## 改完的最小检查
``powershell
node --check index.js
node --check client.js
node tmp\check-write-path.mjs
``

## 局域网
--host 只接受一个具体网卡 IP，配 --trusted-host <ip>:<port>；手机要带完整 ?token=。
