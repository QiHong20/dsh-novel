# 章纲状态线

状态变化挂在场景上，在场景结束时生效；章纲底部汇总本章变化和章末计划值。后续章节没有变化时沿用最近记录，可点击来源返回场景。缺失或歧义章纲会中断继承。

场景人物块之前填写：

```markdown
- 状态对象：guoli
- 状态变化：国力 3210 → 3090
```

多个对象用顿号分隔，变化用分号分隔，各项名称使用对应对象 ID，如 `guoli 3210 → 3090；guoku 32000 → 36600`。

兼容已有章纲：仅绑定一个状态对象且“结果”有唯一明确数字变化时，直接显示该变化。无法识别则提示待核对，不从描述计算或从当前 ledger 倒推。起值与上一记录不一致时显示提醒。当前支持明确的数字前后值。

这是章纲计划线，不是正文事实历史，也不更新 ledger。倒叙或插叙需作者核对：当前沿章节阅读顺序和场景排列展示，不能当作全书绝对时间结算。
