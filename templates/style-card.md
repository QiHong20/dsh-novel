# 文风卡模板（照这个结构写，别照抄内容）

> 用法：自动克隆（`novel_style({ clone: true, source })`）只会生成骨架——
> 统计量、锚点原文、自动挑的禁忌词。**下面六节是「人定的规矩」，必须读过锚点后自己补**。
> 补齐之后 `novel_context` 每次装配都会带上它们（占文风预算的约 40%），`novel_check` 也会按「禁忌」查。

- 来源：哪本书 / 哪几章 / 哪个文件
- 一句话：句均多少字、段均多少字、短句怎么用
- 视角与时态：第三人称限知 / 第一人称 / 过去时 / 现在时

## 一、段落的单位是「一个完整的意思」，不是「一个动作」
- 一段通常几到几句、多少字。
- 句内可以有逗号、转折、补充说明；不要为了「短」把一句话拆成三行。
- 正例：（从锚点里挑一句，逐字抄）

## 二、短句是重音，不是节拍
- 一章里单独成段的短句控制在多少处。
- 只放在三个位置：情绪拐点、信息落点、章末。
- 全篇短句，等于没有重音。

## 三、具体的事，不报数字
- 想表达「惨 / 强 / 有钱」，写场景，不写数据。
- 正例：（一段具体的场景）

## 四、对话
- 标签独立成段，还是贴在引号后；用什么收尾（「道。」「说。」）。
- 同一个人连说几句，要不要重复标签。
- 允许哪些标签（笑骂道 / 反问道 / 低声说 ……），禁止哪些（一律「说道」）。

## 五、旁白的分寸
- 能不能解释、能不能下判断、能不能吐槽；一段几句。
- 正例：（一段带判断的旁白）

## 六、过渡与断场
- 常用过渡句（可就在这时。/ 可没成想。/ 闻言。……）。
- `……` 用来断场、停顿，一章几处。

## 反例（我犯过的错，引以为戒）
- 一句话拆三行：「这套题，他做过。/ 不是做过一遍。/ 是做过两遍。」
- 逐拍清单：「他拿起笔。/ 三分钟。/ 写完了。」
- 分镜脚本：镜头一个接一个，没有「人」在讲。
- 只报数据不写场景：「前世他考了 173 名」。

## 禁忌（不要出现）
- 词：氤氲 / 缱绻 / 心中暗道 / 心头一紧 / 弥漫着 / 洋溢着 / 令人窒息
- 整句（模板腔）：他拿起笔。 / 三分钟。 / 写完了。
- 本书特有的重复用词：（哪句被读者指出来了，就记在这里）
